Error Classification Guide:

Settings (app v1.0.2)

Manage your custom error library, recommendation templates, Excel bulk edit, and where audit notes are saved. These options apply across all audits and are not cleared when you use Refresh on Audit Details.

Error library & templates (JSON)

Export the custom error types you added with “+ Add” in Sections 1–3 and your recommendation templates. Copy the JSON file to another computer, open this app, and use Import so the lists match. Built-in errors always come from the app; this file only carries extras you created.

Excel — errors & recommendations

Excel: Export all error types with Selected (Y/N) and Recommendation side by side. Edit the workbook, then import to sync checkboxes and recommendation text in the current audit.

Where to save audit notes (desktop app)
